# CRM «Отдел продаж»

Учебное приложение к практической работе «Внедрение CRM-системы»
(дисциплина «Внедрение и поддержка компьютерных систем»).

## Как запустить

Откройте `index.html` двойным щелчком в любом современном браузере (Chrome, Edge, Firefox, Яндекс Браузер).
Сервер и установка не нужны. Данные хранятся в браузере на этом компьютере.

Демо-учётные записи:

| Логин | Пароль | Роль |
|---|---|---|
| admin | admin | Администратор |
| head | head | Руководитель отдела продаж |
| petrov, ivanova, kuznetsov, smirnova, orlov | 1234 | Менеджеры пилотной группы |
| fedorova, morozov | 1234 | Менеджеры (подключаются после пилота) |

## Как пункты задания реализованы в приложении

| Пункт задания | Где в приложении |
|---|---|
| Единая база клиентов, история взаимодействия | «Клиенты» → карточка клиента: контакты, заявки, история звонков, писем и встреч |
| Дублирование данных | Предупреждение о дубле при создании клиента; «Перенос данных» → «Дубли в базе» → объединение |
| Перенос базы без потерь | «Перенос данных»: загрузка Excel/CSV, автосопоставление столбцов, сверка «строк в файле = новых + объединённых + пустых» |
| Резервная копия исходных данных | Копия создаётся автоматически перед каждым импортом; «Администрирование» → «Резервные копии» |
| Права доступа (раздел 6) | Роли: менеджер видит только своих клиентов, руководитель — весь отдел и отчёты, администратор — пользователи, пароли, копии |
| Пилотная стратегия (разделы 3–4, 8) | Отметка «пилот» у менеджеров, «Внедрение» → «План внедрения» (9 этапов со статусами) |
| Обратная связь пилотной группы | «Внедрение» → «Обратная связь» |
| Риски (раздел 7) | «Внедрение» → «Риски»: реестр с мерами и статусами |
| Сценарий аварийного отката (раздел 9) | «Внедрение» → «Аварийный откат»: проверка условий (потеря данных, более 30 % группы не могут работать), выгрузка в Excel, восстановление из копии |
| Критерии успешности (раздел 10) | «Внедрение» → «Критерии успеха» и «Отчёты»: считаются автоматически (время поиска клиента, время обработки заявки, % переноса, дубли, активность пилотной группы) |
| Отчётность для руководителя | «Отчёты»: продажи за месяц, воронка, продажи по месяцам, результаты менеджеров, выгрузка в Excel |
| Журнал действий | «Администрирование» → «Журнал действий» |

Для проверки переноса нажмите «Загрузить пример файла» в разделе «Перенос данных»:
в примере есть новые клиенты, дубли существующих и пустая строка.
