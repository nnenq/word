# Практическое занятие № 8-9 — авторизация пользователей (WPF + MS SQL Server + Entity Framework)

## Порядок выполнения

1. **База данных.** Откройте SQL Server Management Studio, подключитесь к серверу,
   откройте `SQL/CreateDatabase.sql` (Файл → Открыть) и нажмите **Выполнить** (F5).
   Создаётся база `UsersDB` с таблицами «Пользователь» и «СекретныйВопрос».
2. **Приложение.** Откройте `UsersApp.sln` в Visual Studio 2022 и нажмите **F5**
   (при первом запуске скачается пакет Entity Framework, нужен интернет).
3. **Сервер.** В окне входа внизу нажмите «изменить» и укажите **то же имя сервера, что в SSMS**
   (например `.\SQLEXPRESS`, `(localdb)\MSSQLLocalDB` или `DESKTOP-XXXX\SQLEXPRESS`), нажмите «Проверить» → «Сохранить».
4. Нажмите «Регистрация», заполните форму, отметьте «Согласен…» и нажмите **ДАЛЕЕ** —
   появится «Пользователь … добавлен». Затем войдите с этим e-mail и паролем.
5. В SSMS выполните `SELECT * FROM dbo.Пользователь` — запись появилась в таблице.

## Скриншоты для отчёта

В отчёте `Отчёт/Отчёт_ПЗ_8-9_Кирчу_Игорь.docx` жёлтым отмечены места для скриншотов:
соединение с сервером в SSMS, диаграмма БД в SSMS, окно регистрации, окно входа,
сообщение «Пользователь добавлен», результат запроса SELECT. Сделайте их (Win + Shift + S) и вставьте вместо жёлтых надписей.

| `UsersApp/MainWindow.xaml` | Окно регистрации (как на рис. 3 методички) |
| `UsersApp/RestoreWindow.xaml` | Восстановление пароля по секретному вопросу |
| `UsersApp/UserWindow.xaml` | Окно пользователя после входа |
| `UsersApp/ServerWindow.xaml` | Настройка имени сервера БД |
