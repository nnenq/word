# CRM «Отдел продаж» — C# WinForms (.NET 8)

Приложение к практической работе «Внедрение CRM-системы»
(дисциплина «Внедрение и поддержка компьютерных систем»).

## Как открыть и запустить в Visual Studio

1. Установите **Visual Studio 2022** (бесплатная Community) с рабочей нагрузкой
   **«Разработка классических приложений .NET»** (.NET desktop development).
2. Скачайте репозиторий: на GitHub кнопка **Code → Download ZIP**, распакуйте архив.
3. Откройте файл `CrmWinForms\CrmSales.sln` двойным щелчком.
4. Нажмите **F5** (или зелёную кнопку «▶ CrmSales»).
   При первом запуске Visual Studio сама скачает библиотеку ClosedXML (нужен интернет).
5. На окне входа щёлкните по демо-учётной записи и нажмите «Войти».

| Логин | Пароль | Роль |
|---|---|---|
| admin | admin | Администратор |
| head | head | Руководитель отдела продаж |
| petrov, ivanova, kuznetsov, smirnova, orlov | 1234 | Менеджеры пилотной группы |
| fedorova, morozov | 1234 | Менеджеры (подключаются после пилота) |

Данные хранятся в файле `Data\crm.json` рядом с программой
(`CrmSales\bin\Debug\net8.0-windows\Data`), резервные копии — в `Data\Backups`.
Если удалить папку `Data`, при следующем запуске создадутся демо-данные.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Models.cs` | Классы данных: пользователь, клиент, заявка, запись истории, этап, риск, отзыв |
| `Db.cs` | Хранение в JSON, резервные копии и восстановление, журнал действий, права доступа |
| `Duplicates.cs` | Поиск дублей по телефону, email, ИНН и названию, объединение |
| `Importer.cs` | Перенос базы из Excel/CSV со сверкой, выгрузка в Excel |
| `Metrics.cs` | Показатели и критерии успешности внедрения |
| `SeedData.cs` | Демонстрационные данные |
| `LoginForm.cs` | Окно входа |
| `MainForm*.cs` | Главное окно: вкладки «Клиенты», «Заявки», «Отчёты», «Внедрение», «Перенос данных», «Администрирование» |
| `ClientCardForm.cs` | Карточка клиента: контакты, заявки, история взаимодействия |
| `ClientEditForm.cs`, `DealEditForm.cs`, `UserEditForm.cs` | Диалоги добавления и редактирования |

## Как пункты задания реализованы

| Пункт задания | Где в программе |
|---|---|
| Единая база клиентов и история взаимодействия | «Клиенты» → двойной щелчок → карточка клиента |
| Дублирование данных | Предупреждение при создании клиента; «Перенос данных» → «Дубли в базе» |
| Перенос базы без потерь (этап 5) | «Перенос данных»: выбор файла, сопоставление столбцов, сверка «строк = новых + объединённых + пустых» |
| Резервная копия исходных данных | Автоматически перед переносом, объединением, удалением и восстановлением; «Администрирование» → «Резервные копии» |
| Участники и права доступа (раздел 6) | Роли менеджер / руководитель / администратор; менеджер видит только своих клиентов; таблица прав во вкладке «Администрирование» |
| Стратегия, план из 9 этапов (разделы 3–5) | «Внедрение» → «План внедрения» |
| Сценарий запуска, пилотная группа (раздел 8) | Отметка «Пилотная группа» у менеджеров; «Внедрение» → «Обратная связь» |
| Риски (раздел 7) | «Внедрение» → «Риски» |
| Аварийный откат (раздел 9) | «Внедрение» → «Аварийный откат»: проверка условий (потеря данных, более 30 % группы), выгрузка в Excel, восстановление из копии |
| Критерии успешности (раздел 10) | «Внедрение» → «Критерии успеха» и «Отчёты»: считаются автоматически |
| Отчётность для руководителя | «Отчёты»: показатели, воронка, продажи по месяцам, результаты менеджеров, выгрузка в Excel |
| Журнал действий | «Администрирование» → «Журнал действий» |

Чтобы показать перенос, откройте «Перенос данных» → «Загрузить пример файла» → «Перенести в CRM»:
в примере 9 строк — 6 новых клиентов, 2 дубля существующих и 1 строка без названия.
