# Кинотеатр «Звезда» — индивидуальная практическая работа, вариант 13

Кирчу Игорь. Тема: «Разработка информационной системы с регистрацией пользователей и разграничением прав доступа».
Предметная область: кинотеатр — фильмы, сеансы и продажа билетов. Роли: администратор, кассир, зритель, гость.

## Как запустить

1. Установите **Visual Studio 2022** с компонентом «ASP.NET и разработка веб-приложений».
2. Откройте `Cinema.sln` и нажмите **F5**. При первом запуске Visual Studio скачает библиотеку
   `Microsoft.EntityFrameworkCore.Sqlite` (нужен интернет).
3. Откроется сайт `http://localhost:5080`. База данных `Cinema/cinema.db` создаётся сама с демо-данными.

Без Visual Studio: установите .NET 8 SDK и выполните в папке `Cinema` команду `dotnet run`.

| Роль | Логин | Пароль |
|---|---|---|
| Администратор | admin | Admin123 |
| Кассир | cashier | Cashier123 |
| Зритель | viewer | Viewer123 |

Чтобы начать с чистыми демо-данными, остановите сайт и удалите файл `Cinema/cinema.db`.
Если база осталась от прошлой версии, при запуске она дополняется сама (столбец постера, сеансы на неделю вперёд) — удалять её не обязательно.

## Что реализовано (по пунктам задания)

| Требование | Где |
|---|---|
| Главная страница с описанием | `/` — `Pages/Index.cshtml` |
| Регистрация (ФИО, логин, пароль, почта, роль) | `/Account/Register`; роль «Зритель» назначается автоматически, другие роли назначает администратор в `/Admin/UserEdit` |
| Авторизация и выход | `/Account/Login`, кнопка «Выйти» — cookie-аутентификация, пароли в виде хеша (`PasswordHasher`) |
| Разделение прав доступа | `Program.cs`: политики `Admin` и `Staff`, закрытые папки `/Admin`, `/Cashier`, `/Cabinet`, `/Tickets` |
| Личный кабинет | `/Cabinet` — мои билеты, возврат, изменение данных, смена пароля |
| Административная панель | `/Admin` — статистика, фильмы, жанры, залы, сеансы, пользователи |
| База данных | SQLite, `Data/CinemaDb.cs`: Roles, Users, Genres, Movies, Halls, Sessions, Tickets со связями |
| CRUD | фильмы, жанры, залы, сеансы, пользователи, билеты (продажа, возврат) |
| Поиск и фильтрация | афиша, расписание, касса, билеты, фильмы и пользователи в админ-панели |
| Проверка данных | атрибуты проверки и проверки в коде: формат, диапазоны, уникальность, пересечение сеансов, занятые места |
| Сообщения об успехе и ошибке | зелёные и красные сообщения вверху страницы (`TempData`), ошибки у полей форм |
| Защита страниц | гость перенаправляется на вход, пользователь без роли видит «Доступ запрещён» |

```

  Models/Entities.cs       таблицы базы данных (классы)
  Data/CinemaDb.cs         связи таблиц, уникальные индексы
  Data/Seed.cs             демо-данные
  Data/TicketService.cs    продажа и возврат билетов

Отчёт/                     отчёт в Word, скриншоты и схемы
```

## Оформление

- Оформление в духе тёмной темы YouTube с синим акцентом: верхняя панель с поиском, меню слева (на широком экране сворачивается до значков), строка жанров, фильмы карточками-превью 16:9, страница фильма как страница просмотра видео.
- Адаптивная вёрстка: на телефоне меню открывается кнопкой ☰, поиск — значком лупы, таблицы превращаются в карточки, схема зала подстраивается под ширину экрана.
- Подтверждение удаления и возврата — своё окно «Да / Отмена» вместо стандартного окна браузера.
- Постер фильма администратор загружает в форме фильма (JPG, PNG, WEBP до 5 МБ), файлы сохраняются в `wwwroot/posters/uploads`.
- На сеанс, который уже начался, билеты не продаются ни на сайте, ни на кассе: в расписании он отмечен «Идёт» или «Завершён», а страница покупки показывает «Продажа билетов закрыта». Проверка дублируется на сервере.
- Расписание при каждом запуске автоматически дополняется сеансами на 7 дней вперёд, чтобы демо-данные не устаревали.
